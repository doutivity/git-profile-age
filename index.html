GitHub account age and developer profile verification

The creation date of a GitHub, GitLab or Bitbucket profile is a small but useful signal when you verify a developer's experience. A profile created in 2012 that matches a résumé claiming ten years of open-source work tells a consistent story. A profile created last month next to a claim of "eight years of GitHub contributions" is worth a follow-up question.

Keep the signal in proportion. Many experienced engineers work in private repositories, switch accounts when they change employers, or simply joined a hosting service late. A young account is a reason to ask, not a reason to reject. Combine the profile age with commit history, project quality and the interview itself.

How to check when a GitHub profile was created

  1. Copy the profile link, for example https://github.com/username. A repository link works too; the tool uses the owner.
  2. Paste it into the field above and press Enter.
  3. Read the exact creation timestamp returned by the API and the calculated profile age.
  4. Use Share result to send a link that opens the same check to a colleague.

What the date means on each service

  • GitHub returns the exact account creation time for users and organizations.
  • GitLab publishes creation dates for groups, but not for personal accounts without signing in. For users, the tool confirms the profile exists and links to the page, where GitLab shows "Member since".
  • Bitbucket exposes the creation date of a workspace. Bitbucket introduced workspaces on 29 November 2018, so accounts older than that show the migration date rather than the original signup.
  • Codeberg, Gitea, Gitee, GitCode and Hugging Face return the account creation date for users; Gitee and Hugging Face do not publish it for organizations.
  • Launchpad, SourceHut, SourceForge, Azure DevOps and NotABug are detected, but their APIs are not usable from a web page without a key or a bot challenge, so the tool links you to the profile page instead.

Privacy

Git Profile Age collects no personal data. There are no analytics, no tracking scripts, no tracking pixels, no cookies, no user accounts and no backend: the site is a single static page. The profile URL you enter is processed in your browser and sent only to the public API of the Git service it belongs to, so that service sees the request like any other visit to its API. Results are cached in your browser's local storage for seven days so repeated checks don't hit the API again; nothing leaves your device apart from that one API request.

The tool cannot control how GitHub, GitLab, Bitbucket or any other service logs API requests. Their own privacy policies apply to those requests.

Перевірка профілю розробника: дата створення GitHub профілю та вік акаунта

Git Profile Age допомагає рекрутерам і hiring-менеджерам швидко дізнатися дату створення GitHub профілю, вік GitHub акаунта, а також дату створення профілю на GitLab, Bitbucket, Codeberg та інших Git-сервісах. Вставте посилання на профіль кандидата, і інструмент автоматично визначить сервіс, звернеться до його публічного API та покаже точну дату реєстрації і вік профілю.

Вік акаунта — це лише один із сигналів під час перевірки досвіду розробника. Він добре доповнює резюме та історію комітів, але не замінює технічне інтерв'ю: багато інженерів працюють у приватних репозиторіях або змінюють акаунти. Використовуйте дату створення профілю як привід для уточнюючого запитання, а не як остаточний висновок.

Сервіс працює повністю у браузері, не збирає персональних даних, не використовує аналітику та трекери. Посилання на профіль обробляється локально і надсилається лише до публічного API відповідного Git-сервісу.
